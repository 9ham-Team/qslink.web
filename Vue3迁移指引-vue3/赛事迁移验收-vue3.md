## 保留的业务和权限 — vue3

- 报名继续调用原 `/entry` 和 `/api/me/cards`，不传入用户、审核状态等身份字段。每件说明 1–2000 个 Unicode 字符，不接受 NUL；历史超过两件的报名完整保留，必须明确移除后才能再次提交，不静默截断。更新携带原 `expectedRevision`，409 保留草稿并阻止直接覆盖，成功刷新后才恢复提交。
- 作品使用独立作品 ID，不用卡片 ID 或展示编号替代。列表不提供快捷投票/点赞；待审核或被拒的说明仍以服务端公开字段为准，不从私人报名缓存补入公开作品。
- 投票只有确认后才发送原 `/vote`，使用原随机浏览器标识存储键；票数/额度在服务端成功返回后更新，未乐观加票。登录身份、截止、重复、五票用尽或资格变化均更新按钮，后台仍为最终权限与配额边界。错误后先尝试复核，无法复核时停用写入；不自动重试追加投票。
- 评委只请求本人 `/judging`、逐件 `/score` 和可选 `/submit`；不调用结果、其他评委或管理员导出接口。轮询不覆盖未保存草稿，草稿携带开始编辑时的单件版本。409 保留草稿并停写，直到用户明确刷新；网络复核失败亦停写，401/403/404 清空私有内容并取消未完成请求。
- 完成标记不锁评分；截止前仍可改分，成功保存使用服务端返回状态清除完成标记。截止用时钟定时更新，同时在写操作前重新检查实际时间；零分作为已评分处理。
- 私有图片只接受严格的本站评审材料路径，Bearer 仅进入请求头，`no-store`、禁止重定向，不拼 token URL、不退回公共上传路径。按作品切换或失去权限时中止请求、回收 Blob URL；元数据轮询不重复加载同一张材料图片。
- 写请求中断不代表服务器未提交。报名和评分以版本保护后续写入，投票有唯一/额度约束，离页结果被忽略后再次进入需读取服务器状态。

## 公共组件与原生适配 — vue3

Vue 负责模板、局部状态、表单、选卡/说明/确认弹窗；新增 Dialog 支持焦点、顶层 Escape 与原模态根协作。未保存评分/报名的链接离开及 beforeunload 提示沿用原行为，不改写全局导航函数或长期分支历史。

3D 和原分享工具是明确的 DOM 子区域：Vue 仅持有空宿主，工具自己创建/修改其内部节点并提供 cleanup；相邻 Vue 内容不交给旧渲染器管理。图片按布局宽度与 DPR 选择；不在旋转帧里重选 src。3D 光晕限制在查看器面板内，避免手机横向扩宽；这不是对既有真机 3D 闪烁问题的修复承诺。

赛事介绍静态文案从旧页面一次性转为真实 Vue 模板绑定（不是 `v-html` 或执行旧页面）。`tools/migrate-contest-static-vue3.mjs` 仅是开发转换工具，不在运行或构建时执行；修改活动文案应维护当前 SFC，并同步核对原生对照及中英文内容。图片继续是已有本站资产，没有 CDN。
