# Vue3 分阶段实施方案 — vue3

当前组合：Vue 3、Composition API、TypeScript SFC、Vite、Pinia 和 Vue Router。Vue3 为本线默认构建与运行入口；源码/配置/脚本使用常规名称，迁移文档保留标识，详见 [命名标准化](命名标准化-vue3.md)。现阶段保持现有 Node.js/CommonJS、PostgreSQL、Sharp、API、CSS tokens、双语词典和法律页。

## 路由与状态所有权 — vue3

P6 的 Router/状态收口已落地：Vue Router 4 与 `createWebHistory()` 独占完整 SPA 路由、守卫、history、滚动和标题；`RouterView` 通过 Teleport 独占 `#app`，导航、页脚、toast、modal 和背景保持为不随页面重建的外壳。已迁移页面直接按需加载真实 Vue 组件；`/admin` 的六个业务分区及比赛投票/人工评审管理已迁入真实 Vue 组件，默认构建不再执行原生后台脚本；详见 [管理后台迁移](管理后台迁移-vue3.md)。

Pinia 的实际 store 是当前用户、公开配置与启动状态的唯一数据源。默认应用不创建 QSL；原状态 getter/setter、全局 router/navigate 桥和页面注册机制已删除。API 模块独立持有 token，通过构造回调通知会话版本；导航服务直接管理同一个 Vue Router，业务页面只依赖注入的模块服务。

统一启动顺序为构造应用服务和 Pinia，再创建 Router 与会话，挂载 AppShell。保留确认离页后的 route:before / route / route:rendered / route:after 顺序以及账户版本重挂、同账号草稿与迟到请求隔离。API、3D、图片、QR/海报算法为标准模块；分享、确认及主页链接弹窗是 Vue 组件。public JS 仅用于独立原生对照，默认入口与法律页不加载这些全局脚本；详见 [移除兼容层](移除QSL兼容层-vue3.md)。
广场已接入滚动续载与短时返回记忆：history.state 仅保存访问标识，公开展示字段快照留在当前标签页内存，最多保留四次访问、十分钟，账号事件清空缓存。浏览器前进/后退恢复对应历史访问；从详情点击未指定筛选的广场面包屑也恢复最近浏览。独立的新访问及显式筛选不串用旧状态，刷新后不承诺保留内存快照。返回时复核已加载各页，未经复核的旧卡片不可交互，已撤下的卡片会从列表移除。复位滚动使用卡片锚点和未变换的布局坐标；用户主动滚动优先于自动恢复，不修改全站 history.scrollRestoration 设置。

## 必须维持的约束 — vue3

- 不为迁移变更数据库结构、鉴权模型、审核流程、注册验证码、内容授权或地址可见性。
- 3D 角度、惯性和 rAF 留在引擎；组件只传低频参数及调用 setter，不逐帧进入响应式状态。保留布局宽度 × DPR 的图片规则，不按旋转 bounding box 选图。
- 不用 `v-html` 渲染用户输入；模板插值走 Vue 转义。分享和通用弹窗由 Vue 组件渲染，算法模块不得重新引入旧 modal DOM 岛。
- 每次请求有取消与过期保护；卸载、参数和账号变化均考虑。网络返回后先确认页面实例有效，再更新状态或 toast。
- 图片处理已使用独立 module Worker，经 Vite 生成哈希 URL；离页终止工作线程，保留能力探测、取消及主线程降级。
- 法律页继续独立提供双语静态版本；现有语言偏好和重载守卫保持。新增用户可见文案必须同步词典。
- 复用六份原 CSS 顺序；不引入 UI 组件库整体替换视觉，不把 SSR/SEO、3D 闪烁修复或服务器搬迁混入第一轮。

## 验证与回退 — vue3

常规检查：`npm run check`、`npm run test:unit`、`npm run build`、`npm run test:e2e`、`git diff --check`。涉及服务端/权限/数据时运行原 `npm test`、`npm run test:production`。

浏览器测试使用独立临时 PostgreSQL 和合成种子，不接触真实数据；桌面及手机视口覆盖主页功能、资源加载、控制台、路由返回和迟到响应。组件测试覆盖排序失败重试、转义、账号变化、请求中止、图片观察器和 3D 销毁。视口模拟不能替代 Android/iOS 真机 3D 视觉测试。

默认 Vue3 入口为 `npm run build` 后执行 `npm start`；原生对照使用 `npm run start:legacy`。框架产物与数据分离；旧镜像/页面仅恢复程序，不能撤销用户新产生的库存、换卡或投票。远程发布/回退仍需逐次授权，44381 与归档 44380、main/生产保持隔离。
